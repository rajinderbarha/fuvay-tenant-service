# Service Catalog Specification

List view target: `/provider/services` (consolidation target per
tenant-route-duplication-map.csv). Multi-service setup wizard reuses
`SetupWizard` pattern (bulk entry + per-service override step, draft/resume,
validation) — see multi-service-setup-wizard.md. Service Detail page
(service-detail-specification.md) adds a configuration-health checklist
(pricing set, service area coverage set, at least one qualified technician,
media present).
