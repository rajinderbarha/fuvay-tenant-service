# Assignment / Dispatch Pattern

`components/ux03/patterns/OperationalWorkspace.tsx` — three-column layout
(queue / detail / side context), demoed at `/dev/ux-03/dispatch-workspace`
with an unassigned-jobs queue and a technician availability/skills side
panel. Does not claim AI-based matching — the repo's actual dispatch
capability was not confirmed as AI-driven this phase, so the pattern only
surfaces availability, skills, and workload as plain data.
