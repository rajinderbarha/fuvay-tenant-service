# Business Settings Pattern

`/dev/ux-03/settings` demonstrates the save-bar/unsaved-change pattern: a
dirty-state banner (`Alert tone="warning"`) plus a sticky save-bar
appearing once any control changes, with Discard/Save actions. A
read-only, permission-restricted section is shown disabled with an
explanatory note (owner-only). Sections to cover in the full page: details,
hours, booking prefs, notifications, service defaults, locale, branding,
security, team defaults — only "hours" and a stubbed "booking preferences"
section are demoed this phase (see deferred-items.md).
