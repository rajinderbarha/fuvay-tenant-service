# Multi-Service Setup Wizard

Built on the same `SetupWizard` pattern as the first-time business setup
(see first-time-setup-workflow.md), with steps: select services (bulk) ->
per-service overrides (price, brand, zone-specific tweaks) -> validation
summary -> save draft / publish. Not built as a separate dev-showcase route
this phase (see deferred-items.md) — the mechanism is demonstrated by
`/dev/ux-03/setup-wizard`.
