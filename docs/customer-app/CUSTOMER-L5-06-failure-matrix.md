# CUSTOMER-L5-06 — Failure Matrix

| Failure | Detection point | Customer impact | Screen state | Message | Retry | Draft reconciliation | Analytics | Log level | Severity |
|---|---|---|---|---|---|---|---|---|---|
| Draft creation fails — offering ID mismatch (`HOME_BOOKING_OFFERING_INVALID`) | 422 from `createDraft` | Cannot proceed to draft/media at all | Full-page error | "This service isn't available for booking yet" | Exit to service detail | N/A — no draft created | Implicit `draft_create_failed` | warn | P0 (structural, see known-gaps) |
| Draft creation fails — other reason | 4xx/5xx from `createDraft` | Same | Same | Same | Same | Same | Same | warn | P1 |
| Draft restore fails (cached ID stale/invalid) | `useDraft` `isError` on the cached ID | Transparent — falls through to creating a new draft | (No user-visible error — automatic fallback) | N/A | N/A | New draft created | `draft_restore_failed` | warn | P3 |
| Draft is expired | `draftLoaded()` classifies `status==="expired"` or `isPastExpiry()` | Cannot continue this draft | Full-page error | "This booking draft has expired" | "Start again" → clears pointer, returns to service | N/A | N/A | N/A | P2 |
| Draft is cancelled | `draftLoaded()` classifies `status==="cancelled"` | Same | Full-page error | "This booking was discarded" | Same | N/A | N/A | N/A | P2 |
| Assistant-answer sync fails | `useUpdateDraft` `onError` | Draft still usable; synced fields (brand/type/summary) just didn't save | Inline "Couldn't save" text, non-blocking | `draft.saveFailed` | Not automatic — customer can still continue; a future edit would retry implicitly | Draft state unchanged from before the failed sync | Implicit | warn | P2 |
| Media validation failure (wrong type/too large/count limit) | `validateMediaCandidate` | That one photo is rejected before any network call | Inline "unsupported/too large/limit reached" thumbnail label | `media.unsupportedFile`/`fileTooLarge`/`maxReached` | Pick a different file | N/A | `media_validation_failed` | info | P3 |
| Upload fails (media engine) | `uploadPhoto` mutation error | That photo shows a failed state | Inline "Upload failed" thumbnail | `media.uploadFailed` | Manual retry (up to 3x, then stuck — see known-gaps) | No asset created | `upload_failed` | warn | P2 |
| Link-to-draft fails after a successful upload | `linkPhoto` mutation error | Photo uploaded but not yet visible on the draft | Inline "Upload failed" (same visual state as an upload failure — see known-gaps) | `media.uploadFailed` | Manual retry — retries only the link call, not the upload | Orphaned `MediaAsset` until link succeeds or customer gives up | `upload_failed` | warn | P2 |
| Delete fails | `deleteMedia` mutation error | Photo remains visible | No dedicated error UI this pass | N/A | Implicit — customer can tap delete again | N/A | `media_delete_failed` | warn | P3 |
| Draft cancel fails | `cancelDraft` mutation error | Local pointer still cleared, customer still navigated away (local cleanup proceeds regardless) | N/A (navigation proceeds) | N/A | N/A | Draft may remain non-terminal server-side despite the local UI treating it as discarded — see known-gaps | `draft_cancel_failed` | warn | P2 |
| Offline | Existing `ApiError` `network_error` category on any of the above | Same generic failure UI per-operation | Various (see above) | Generic error text | Yes, once reconnected | Unaffected (no local-only progression exists to roll back) | N/A | N/A | P3 |
| Logout/account switch during a draft/media operation | `queryClient.clear()` + local pointer clear (CUSTOMER-L5-02 pattern, reused) | In-flight screen state becomes stale; navigation redirects away | Redirected to Authentication/BaselineLanding | Existing auth flow copy | N/A | Draft/media caches discarded; no foreign state persists | N/A | N/A | NOT_APPLICABLE (correct behavior) |
| Wrong customer / wrong tenant | Backend 403/404 on any draft or media endpoint | Operation fails safely | Generic error state for that screen | Generic error text | Where applicable | No foreign data ever rendered | Implicit | warn | P1 |
